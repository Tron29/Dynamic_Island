# Sound sources

Bell, Chime and Drop are generated for this project.

iOS Tri-tone is Apple's classic sms-received1.caf notification sound, converted to PCM WAV for Windows playback. Source: https://ios6.tamasina.com/Sounds_Unconverted/UISounds/sms-received1.caf (archive index: https://ios6.tamasina.com/Sounds_Unconverted/UISounds/index.html). Apple remains the original rights holder; the conversion does not change ownership.
